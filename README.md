# LexCity

**Equality. Justice. For everyone.**

LexCity is a civic platform built to make fairness visible and actionable — connecting people to legal aid, civic education, and the organizers working to close the gap between the law as written and the law as lived.

## ✨ Features

- Interactive 3D hero animation (rotating scales of justice) built with Three.js
- Smooth scroll-triggered reveals
- Cursor-reactive lighting and parallax
- Fully responsive, single-file build — no dependencies to install
